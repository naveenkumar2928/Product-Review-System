
# Product Review System

A web-based application developed using Python Flask, HTML, CSS, and SQLite to manage product ratings and customer reviews.

## Overview

The Product Review System enables users to register, log in, explore products, submit ratings, and share their feedback. It also provides a dashboard to view review statistics and product ratings.

## Key Features

- User Registration and Authentication
- Secure Password Storage
- Product Rating and Review Submission
- Display of Customer Reviews
- Product-Wise Rating Statistics
- Dashboard with Charts
- SQLite Database Integration

## Products

- Wireless Headphones
- Smart Watch
- Bluetooth Speaker

## Technology Stack

- **Programming Language:** Python
- **Framework:** Flask
- **Frontend:** HTML5, CSS3
- **Database:** SQLite
- **Charts:** Chart.js

## Installation and Usage

**1. Clone the repository**

    git clone https://github.com/gowthamimurakonda2928/Product-Review-System.git

**2. Navigate to the project directory**

    cd Product-Review-System

**3. Install dependencies**

    python -m pip install -r requirements.txt

**4. Run the application**

    python app.py

**5. Open the application**

    http://127.0.0.1:5000
